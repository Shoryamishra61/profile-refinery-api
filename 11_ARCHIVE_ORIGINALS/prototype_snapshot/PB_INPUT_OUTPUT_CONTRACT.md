# Forensic Black-Box Contract Analysis: PhantomBuster
This document details the observed input requirements, output schemas, and data structures of PhantomBuster's LinkedIn Profile Scraper, evaluating the structural differences between flat-CSV and nested-JSON formats.

---

## 1. Input Specifications
For any automated run, PhantomBuster’s cloud containers expect a rigid input payload structure. These are configured via the UI or passed as a JSON document in API v2 `/agents/save` calls.

| Parameter Key | Type | Requirement | Description |
| --- | --- | --- | --- |
| `sessionCookie` | String | **Mandatory** | The active LinkedIn `li_at` cookie value used to authenticate the raw network connection to LinkedIn's servers. |
| `userAgent` | String | **Mandatory** | The browser User-Agent string coupled to the browser session that generated the `sessionCookie`. |
| `spreadsheetUrl` | String | Optional | The URL of a publicly shared Google Sheet containing the target LinkedIn profile URLs in column A. |
| `urls` | Array | Optional | An array of plain-text LinkedIn profile URLs to extract. Used as an alternative to `spreadsheetUrl`. |
| `numberOfProfilesPerLaunch` | Integer | Optional | The number of profile URLs processed during this specific execution run. Defaults to `200`. |
| `companyEnrichment` | Boolean | Optional | Toggle to execute background enrichment requests against the target's current employer's company URN. |
| `emailDiscoveryService` | String | Optional | Dropdown selector to trigger secondary API calls to verified email providers (Dropcontact, Hunter, Snov.io). |

## 2. Output Schema & Format Transformations
PhantomBuster executes the requested extraction and saves the final result files directly into the workspace's cloud storage bucket. The structure of this output is highly dependent on the chosen format:

### A. Flat CSV Format (Standard Google Sheets Output)
Because standard spreadsheets lack nested object arrays, PhantomBuster automatically flattens complex arrays (such as career and educational histories) into predefined, numbered column keys.
* **The Structural 2-Job Ceiling:** The Profile Scraper flattens experience data into exactly two sets of columns:
    * Current Experience: `linkedinJobTitle`, `linkedinJobDateRange`, `linkedinJobLocation`, `linkedinJobDescription`.
    * Immediate Previous Experience: `linkedinPreviousJobTitle`, `linkedinPreviousJobDateRange`, `linkedinPreviousJobLocation`, `linkedinPreviousJobDescription`.
* **The Structural 2-School Ceiling:** Educational history is similarly flattened:
    * Recent Education: `linkedinSchoolName`, `linkedinSchoolUrl`, `linkedinSchoolDegree`, `linkedinSchoolDateRange`.
    * Previous Education: `linkedinPreviousSchoolName`, `linkedinPreviousSchoolUrl`, `linkedinPreviousSchoolDegree`, `linkedinPreviousSchoolDateRange`.
* **Consequence:** If a profile contains 15 experience entries, entries 3 through 15 are permanently discarded in the flat CSV.

### B. Nested JSON Format
When downloading the results as `result.json`, the data is theoretically capable of holding nested arrays. However, a critical forensics check reveals that **the Profile Scraper still applies the 2-job truncation internally**. The JSON payload is generated by converting the flattened CSV structure back into JSON keys rather than capturing the full backend array. Only the **Profile Visitor** outputs an unlimited, deeply nested JSON array of the complete career history.

### C. Missing-Field Semantics
* **CSV Behavior:** Missing or inaccessible fields (e.g., an empty "About" section or hidden connection counts) are represented as completely empty cells (null values between consecutive commas: `,,`).
* **JSON Behavior:** If a field is missing, the key is omitted entirely from the object to minimize payload size, rather than being explicitly written as `null` or `""`.

## 3. Plan-Level Constraints (Free Trial vs. Paid)
PhantomBuster enforces strict limits at the API level depending on the subscription tier:
* **Free / Trial Plan Restrictions:**
    * CSV downloads are artificially truncated to the **first 10 rows** of results.
    * Direct JSON exports (`result.json`) are completely disabled.
    * Spreadsheet inputs via public CSV files are unsupported.
* **Paid Plans:** Full CSV and JSON export links are fully generated and accessible programmatically.
