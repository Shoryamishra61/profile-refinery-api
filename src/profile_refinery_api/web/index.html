BACKEND INTEGRATION

Use Profile Refinery as an API

Call the request-scoped endpoint from your own backend. No Profile Refinery API key is required; your authorized LinkedIn session is carried in that single request and is never returned.

POST https://profile-refinery-api.vercel.app/v1/session-extractions OpenAPI explorer OpenAPI JSON

Python backend

import os
import requests

payload = {
    "urls": ["https://www.linkedin.com/in/example/"],
    "session": {
        "li_at": os.environ["LINKEDIN_LI_AT"],
        "jsessionid": os.environ["LINKEDIN_JSESSIONID"],
        "companion_cookies": os.getenv("LINKEDIN_COOKIE"),
        "user_agent": os.environ["LINKEDIN_USER_AGENT"],
        "accept_language": "en-US,en;q=0.9",
    },
}

response = requests.post(
    "https://profile-refinery-api.vercel.app/v1/session-extractions",
    json=payload,
    headers={"X-Request-ID": "your-correlation-id"},
    timeout=120,
)
response.raise_for_status()
data = response.json()

Node.js backend

const response = await fetch(
  "https://profile-refinery-api.vercel.app/v1/session-extractions",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-Request-ID": crypto.randomUUID(),
    },
    body: JSON.stringify({
      urls: ["https://www.linkedin.com/in/example/"],
      session: {
        li_at: process.env.LINKEDIN_LI_AT,
        jsessionid: process.env.LINKEDIN_JSESSIONID,
        companion_cookies: process.env.LINKEDIN_COOKIE,
        user_agent: process.env.LINKEDIN_USER_AGENT,
        accept_language: "en-US,en;q=0.9",
      },
    }),
  },
);

if (!response.ok) throw new Error(`HTTP ${response.status}`);
const data = await response.json();
HTTP 200 ENVELOPE

Per-profile results

Each item is succeeded, partial, failed, or skipped. An invalid URL becomes a failed item with INVALID_PROFILE_URL; it never reaches LinkedIn.

HTTP 422

Invalid request body

Missing session fields, more than 10 URLs, or malformed field types fail request validation without echoing secret values.

HTTP 429 / 5XX

Typed operational errors

Rate limits, challenges, session expiry, timeouts, and protocol drift remain explicit. Inspect each result’s error.code before retrying.

Backend use only. Keep LinkedIn cookies in a secret manager or environment variables. Never embed them in browser JavaScript, mobile apps, logs, databases, URLs, or source control.

OUTPUT CONTRACT

What this refinery actually returns

Observed fields are emitted with provenance and explicit availability. Missing upstream evidence stays missing.

OBSERVED

Identity & overview

Name, first/last name, headline, location, about, profile URL, public identifier, member URN, profile and background images.

OBSERVED

Career & education

Experience, company, title, dates, descriptions, locations, education, skills, certifications, and languages when visible.

NOT INVENTED

Outside the current contract

Professional email, company industry/website, follower and connection counts, connection degree, hiring badge, and mutual-connection URLs.
